# Plexi Overlay

Plexi overlay cut file for the Panzer SLAB. **Works on all SLABs.**

## What's in This Folder

- `panzer-slab.svg` — full overlay outline: all button openings, case outline, and mounting holes

## Material

Use **1.5mm (1/16") plexi/acrylic**.

## Usage

The file works two ways:

- **Direct cutting** — send it straight to a laser cutter or CNC as-is.
- **Art template** — use it as the template layer in your design software to line artwork up with the button openings and case outline before cutting.
